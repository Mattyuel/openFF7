# Inventory

Generated by `python3 tools/ff7tool.py inventory`. Do not edit by hand.

| File | Contents |
|---|---|
| `fields.csv` | One row per field: id, location name, story-progress checks (count, min, max), story values it sets, exits, scripted battles, random encounter formations. |
| `locations.md` | The same fields grouped by in-game location name. |
| `field_links.csv` | Field-to-field connections (`MAPJUMP` instructions). |
| `scripted_battles.csv` | Every fixed battle started from a field script, with enemies, level, whether escape is blocked, and where it happens. |
| `formations.json` | All 996 battle formations in `scene.bin`. |

## Key numbers

- 702 field files (plus 27 texture/data entries in `flevel.lgp`).
- 391 fields branch on story progress (`var[2][0]`); 213 fields advance it.
- 131 battle formations are started directly from field scripts. About 20 of
  these are in the Gold Saucer Battle Square (`clsin2_1`), which picks
  opponents from many areas.
- Battles started with a formation held in a variable, and world map battles
  (e.g. Ruby/Emerald Weapon), are not listed yet.
