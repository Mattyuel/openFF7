# Inventory

Generated by `python3 tools/ff7tool.py inventory`. Do not edit by hand.

| File | Contents |
|---|---|
| `fields.csv` | One row per field: id, location name, story-progress checks (count, min, max), story values it sets, gateways (walk-off exits), script exits, scripted battles, random encounter formations. |
| `locations.md` | The same fields grouped by in-game location name. |
| `field_links.csv` | Field-to-field connections: walk-off gateways (kind `gateway`) and script `MAPJUMP`s (kind `script`). World map destinations are `wm0`–`wm63`. |
| `scripted_battles.csv` | Every fixed battle started from a field script, with enemies, level, whether escape is blocked, and where it happens. |
| `formations.json` | All 996 battle formations in `scene.bin`. |

## Key numbers

- 702 field files (plus 27 texture/data entries in `flevel.lgp`).
- 391 fields branch on story progress (`var[2][0]`); 213 fields advance it.
- 131 battle formations are started directly from field scripts. About 20 of
  these are in the Gold Saucer Battle Square (`clsin2_1`), which picks
  opponents from many areas.
- Battles started with a formation held in a variable, and world map battles
  (e.g. Ruby/Emerald Weapon), are not listed yet.
| `worldmap.md` | World map entrances (`field.tbl`: which room each world map location leads to, and which script function enters it) and every story-progress check in the world map script. |

## World map findings

- `wm0.ev` is the main world map script (`wm2.ev` underwater, `wm3.ev` snowfield).
  Only about 25 checks of story progress exist there, so the world map is much
  simpler to open up than the fields.
- Entry `wm0` (Midgar, leading to `mds5_5` in the Sector 5 slums) exists in
  `field.tbl`, but **no world map script calls it**. Re-entering Midgar on foot
  needs a new world map trigger.
